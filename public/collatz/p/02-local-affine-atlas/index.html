Collatz Local Affine Atlas：有限奇偶字的精確仿射化

Finite-Word Affine Closure、Count/Order Decomposition 與字序修正。建立系列第一個核心數學層:證明任意長度 k 的有限奇偶字 w 對 modified Collatz map 均對應一個精確仿射算子 F_w(x) = (3^u(w) x + b_w) / 2^k。

有限奇偶字精確仿射封閉性:F_w(x) = (3^u x + b_w) / 2^k 本文明確不證明「∀n, T^j(n)=1」、不證明所有無限奇偶序列最終含下降前綴、不從 u/k 的平均值推出全域收斂——只證明有限字本身的精確仿射結構。
