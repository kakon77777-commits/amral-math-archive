錨定區間 Weil–Toeplitz 橋接

對 v1.4 的對角恆等式做正規化稽核,發現若要把完整 screw kernel 解讀成矩形 basis 的 Weil Gram matrix,必須改用「共同左端點」的錨定區間指示函數,才能得到精確的全矩陣恆等式。對此取差分後證明局部 box Gram matrix 是精確的 Toeplitz 矩陣,且任一固定大小的 box matrix 只需有限個質數冪資料。另證明第二個 no-go:固定孔徑時,RH 下該 Toeplitz 矩陣的譜測度是純原子測度,其巢狀 Schur innovation variance 必趨於零,連經正規化的 reserve 也不能期待一致正下界。

RH_CLAIM = False 若 RH 成立,uniform-box nested Schur innovation 不可能有固定正下界;uniform determinant/eigenvalue/Schur-innovation 下界都不可作為證明目標,合理方向是「符號正確、精度隨尺度調整」而非固定 margin;新的 box matrix 是否等於原本的 arithmetic matrix,也尚未證明。
