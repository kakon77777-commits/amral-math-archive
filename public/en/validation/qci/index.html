QCI — Quantitative Closure Interface

A legitimacy, admissibility, estimate-precision, error-control, and uniform-quantification layer that a proof strategy relying primarily on qualitative, topological, geometric, algebraic, or combinatorial structure must pass through before being promoted to a global analytic/arithmetic claim. Qualitative arguments often "feel right" intuitively, but don't account for whether constants are uniform, whether error is controlled, whether tails have been handled, or whether local results can actually glue into a global one — QCI fixes these questions into a checklist that must be answered item by item, rather than leaving it to the reader to fill in the gaps.

T → Φ → A_admissible → Q → R — The qualitative argument T is filtered by Φ into an admissible form A_admissible, then quantified by Q, yielding the result R.

Core Pipeline

\[ \mathcal T \xrightarrow{\Phi} \mathcal A_{\mathrm{admissible}} \xrightarrow{Q} \mathcal R \]

Where \(\mathcal T\) is the original qualitative/structural argument, \(\Phi\) is the map that filters and rewrites it into an admissible form, \(\mathcal A_{\mathrm{admissible}}\) is the intermediate form that has passed the legitimacy check, \(Q\) is the quantification operator, and \(\mathcal R\) is the final, checkable quantitative result.

QCI Debt

Any argument that claims to have achieved QCI closure must be able to account for the status of each of the following nine components:

\[ D^{\mathrm{QCI}} = ( D_{\mathrm{def}}, D_{\mathrm{adm}}, D_{\mathrm{quant}}, D_{\mathrm{uniform}}, D_{\mathrm{error}}, D_{\mathrm{tail}}, D_{\mathrm{global}}, D_{\mathrm{consistency}}, D_{\mathrm{formal}} ) \]

  • D_def — whether the object has a clear definition (well-definedness);
  • D_adm — whether it passes the admissibility check;
  • D_quant — whether there is a clear quantitative bound;
  • D_uniform — whether the bound is uniform across the relevant parameter range;
  • D_error — whether error terms have been estimated and controlled (error budget);
  • D_tail — whether tail behavior has been handled;
  • D_global — whether local results genuinely glue into a global conclusion (local-to-global);
  • D_consistency — whether it is consistent with known results and special cases;
  • D_formal — whether it has (or needs) formal verification (formalization).

QCI Status Display Format

If a case applies QCI, the suggested item-by-item status display is as follows (not yet applied to any existing case):

QCI
✓ Well-definedness
✓ Admissibility
△ Quantitative bound
✗ Uniformity
△ Error budget
N/A Tail
✗ Local-to-global
✓ Consistency
○ Formalization

The overall status is fixed to one of five values: CLOSED / PARTIAL / OPEN / FAILED / N/A.
