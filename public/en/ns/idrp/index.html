NS-IDRP

Navier–Stokes Impulsive Defect Recurrence Program · Cycle IX · 4/4 built · global regularity OPEN

NS-IDRP is the first sub-line in the relay to continue directly from NS-DCRP — its own opening line states "DCRP Cycle VIII closes with the surviving normal form 𝒦_IDR (diffuse impulse recurrence)," the first place confirming NS-DCRP is in fact Cycle VIII. The core new question is temporal: can every positive carrier exist only at isolated moments, keeping every spacetime budget summable? Four rounds carry this forward: IDRP-01 separates persistence from burst debt; IDRP-02 proves that rapid loss of a filtered trace is not mechanism-invisible; IDRP-03 partially closes the burst-to-defect-realization (BDR) problem; IDRP-04 completes the Cycle IX final audit.

IDRP-04 concludes that source transversality from pressure alone is generally impossible, that the stronger "forcing pairing implies source defect" theorem also fails, and that the universal weak source-action budget is summable in scale — so it cannot by itself supply a physical critical lift. Cycle IX thereby reduces the surviving obstruction to a tangential singular-impulse phantom (TSIP), formally handing off to "NS-TSKR: Navier–Stokes Tangent Singular Kernel Rigidity Program." The confirmed relay so far: NS-CSP (II) → NS-DRC (III) → NS-ANP (IV) → NS-CFOP (V) → NS-FCBP (VI) → NS-MORP (VII) → NS-DCRP (VIII) → NS-IDRP (IX) → NS-TSKR (X) → NS-RKAP (XI).

Cycle IX, four rounds · The Four-Paper Cycle

Dependency chain: persistence-vs-burst dichotomy → burst visibility → burst-to-defect realization → closing audit. Reading in order is recommended — each round takes the previous one's results as given.

IDRP-01

Impulse Persistence, Trace Thickening, and Recurrent Defect Normal Forms

Separates persistence from burst debt, proves an energy-class persistence lower bound, but shows the general modulus is too weak to force parabolic thickening. Opens Cycle IX.

 IDRP-02

Source-Impulse Visibility and Moving-Window Depletion

Proves rapid loss of a filtered vorticity trace is not mechanism-invisible; defines the burst-to-defect-realization (BDR) bridging problem.

 IDRP-03

Relative Invisible Burst Kernels and Dual-Compatible BDR

Proves a partial BDR lower bound via a finite-window source quotient, and a compact-family moving-window theorem excluding relative invisible bursts.

 IDRP-04 · final audit

Source Transversality, Adjoint Synchronization, and the Cycle-IX Closure Audit

Proves source transversality from pressure alone is impossible. Reduces the obstruction to a tangential singular-impulse phantom and hands off to NS-TSKR.
