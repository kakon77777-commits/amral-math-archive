Relative Invisible Burst Kernels, Dual-Compatible Burst-to-Defect Realization, Amplitude-Normalized Audit, and Temporal Rigidity

IDRP-02 established: rapid filtered-trace loss ⟹ an explicit mechanism burst; fresh causal source pairing ⟹ an L_t^(4/3) weak source-action burst. What remains is the burst-to-defect-realization (BDR) bridge. This paper partially closes the BDR problem via an exact native route through a finite-window source quotient: in a finite-dimensional Hilbert source-coordinate model, if the source dual pair induced by a causal forcing burst has a fixed transverse component against the clean/model source subspace, it forces a quantitative source-quotient distance — and if a sharp packet norm dominates this native source coordinate, a non-tautological BDR lower bound follows. It proves an approximate causal–audit dual-compatibility compiler, transferring causal source pairing to native audit-residual pairing. It proves a compact-family moving-window theorem: operator-norm precompactness plus kernel-freeness of every limit map gives a uniform positive minimum singular value, excluding every relative invisible burst.
