NS-ANP

Navier–Stokes Ancestry Necessity Program · Cycle IV · 10/10 built · global regularity OPEN

NS-ANP continues from NS-DRC Cycle III's result: DRC completes reservoir-mechanism classification closure on the Type-I branch, but the audit finds closure does not imply chain necessity, identifying source–core ancestry, recursive-edge compatibility, and non-Type-I entry as the main gaps. Ten rounds build a formal theory of pre-singularity causal ancestry: ANP-00 defines the causal relation domain, ANP-01 through 03 progressively upgrade source–core ancestry from weighted adjoint contributions to a genuine C3 causal parent edge, ANP-04 fills in non-Type-I entry, ANP-05 through 08 handle arbitrary-depth paths, an inheritance-criterion correction, horizon persistence, and transmission rigidity, ANP-09 completes the Cycle IV final audit.

ANP-09 proves a genuine Horizon Causal-Forest Necessity Theorem (CN_Forest): assuming a finite-time singularity, a pre-singularity causal DAG actually exists in the original solution, with terminals appearing at arbitrarily late times and unbounded singular scales. But atomic CN3 (a single infinite causal lineage) remains OPEN — the irreducible frontier is a diffuse horizon branch; the dangerous causality may be an entire forest, not a single lineage. Formally hands off to "NS-CFOP: Navier–Stokes Causal Forest Obstruction Program." This is a middle segment of the research line: NS-DRC (Cycle III) → NS-ANP (Cycle IV) → NS-CFOP (Cycle V) → NS-FCBP (Cycle VI) → NS-MORP (Cycle VII) → NS-DCRP. The previous round's "possibly related, unconfirmed" reference to a "DRC dissipation-wavenumber architecture" is now confirmed — it is NS-DRC Cycle III itself.

Cycle IV, ten rounds · The Ten-Paper Cycle

Dependency chain: causal relation domain → source–core ancestry → C3 causal parent edge → universal entry → arbitrary-depth paths → inheritance correction → horizon persistence → transmission rigidity → causal-forest final audit. Reading in order is recommended — each round takes the previous one's results as given. ANP-05's original inheritance criterion was later flagged as too strong by a v0.2 correction note accompanying ANP-06; the correction is linked from that round's page.

ANP-00

Pre-Singularity Causal Relation Domain and Hybrid Continuity

Defines the canonical causal atom and the rules every ancestry edge must satisfy. A pure framework document. Opens Cycle IV.

 ANP-01

Source–Core Provenance, Adjoint Causal Tubes, and the C2→C3 Gap

Proves a weighted forward causal-ancestry identity, obtaining a genuine C2 PDE causal edge. Geometric parent-source localization remains open.

 ANP-02

Recursive Edge Compatibility, Adjoint-Footprint Aperture, and the Parent-Localization Gap

Introduces canonical footprint spectral nodes stable under backward recursion; proves a functional-analysis NO-GO: adjoint-weight localization does not imply source localization.

 ANP-03

Source-Parent Recapture, Kernel-Inflated Footprints, and the C3 Causal Upgrade

Proves a weighted C3 causal parent edge for strong source atoms — the first genuine ancestry upgrade (restricted to a weighted quasi-local footprint-node class).

 ANP-04

Non-Type-I Ancestry Entry and Universal Causal-State Initialization

Proves non-Type-I failure does not block causal-state initialization, obtaining a universal two-branch causal-state entry theorem.

 ANP-05 · See correction

Arbitrary-Depth Compatible C3 Paths and No-Terminal-Node

Proves a no-terminal-node theorem and the existence of arbitrary finite-depth compatible C3 paths. The original inheritance criterion was later flagged as too strong by a v0.2 correction note.

 ANP-06

Singular-Horizon Infinite Ancestry Extraction and Dual-Propagator Correction

Corrects ANP-05's inheritance criterion; proves that finite-depth realizability does not imply infinite-branch existence; defines the horizon-persistent node.

 ANP-07

Horizon-Persistent Branch Extraction and Causal Edge Closure

Splits horizon-persistence failure into transmission degeneration and compactness degeneration; proves a local causal-edge closure theorem.

 ANP-08

Horizon Transmission Rigidity and Actual-Branch Shadowing Audit

Proves horizon-transmission collapse is not an independent obstruction; gives an explicit counterexample where profile compactness does not shadow the actual chain.

 ANP-09 · Final audit

Scale-Fragmentation Rigidity, Causal-Forest Necessity, and the CN3 Audit

Proves the Horizon Causal-Forest Necessity Theorem (CN_Forest). Atomic CN3 remains OPEN. Hands off to NS-CFOP.

On the source file format

The ten rounds exist in the source drop only as .zip release bundles (each containing the paper .md, a versioned roadmap, CHANGELOG, etc). ANP-06's release bundle additionally contains a v0.2 correction note for ANP-05, published here and linked from the ANP-05 page. The roadmap/CHANGELOG/schema files inside each bundle are internal project-management documents and are not published. Download the Cycle IV handoff, original .md (English)
