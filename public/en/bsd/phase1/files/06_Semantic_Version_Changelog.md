# 06 | Semantic Version Changelog

Theorem-producing code must additionally maintain a "mathematical semantic version"; one cannot rely solely on Git commits.

Monitoring:

1. $p$-isogeny and $a_3$ gate;
2. $\gcd(d,3N)=1$;
3. Whether BSD$(E,2)$ is a necessary condition or a complete certificate;
4. $\Sha[2]$ verification for $E'$;
5. Whether $\mathcal S$ is a deterministic criterion or a bounded search;
6. testing flags;
7. Whether timeout is FAIL or UNKNOWN;
8. Whether algebraic rank and analytic rank are in separate columns.

Principle:

$$
\boxed{
\text{code version}
\neq
\text{theorem semantics version}.
}
$$
