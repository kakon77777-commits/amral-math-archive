Arithmetic Matrix and Positive Semi-Definite Certificate Prototype

Arithmetic Matrix / PSD Prototype v0.1 — Establishes M_arith(R) = M∞(R) + M_fin(R) on a real even compactly supported basis, calculating the minimum eigenvalue for each support radius R∈{0.25,...,1.00}. The finite position matrix itself has clear negative directions, but after adding the Archimedean part, the total matrix maintains a positive minimum eigenvalue throughout the currently scanned subspace.

This is not an RH proof, nor is it a strict PSD certificate — The phased status stated by the document in the package, reproduced exactly as is.
