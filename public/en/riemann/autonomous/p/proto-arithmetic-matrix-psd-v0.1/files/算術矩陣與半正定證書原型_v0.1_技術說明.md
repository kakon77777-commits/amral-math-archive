# Arithmetic Matrix and Positive Semi-Definite Certificate Prototype v0.1

## I. Purpose

This engineering package converts the following expression from the theoretical document:

\[
M_{\mathrm{arith}}(L)
=
M_\infty+
\sum_{m\log p\le L}M_{p,m}
\]

into a reproducible finite-dimensional scanner. The program does not attempt to prove the RH directly, but rather answers three engineering questions:

1. For a fixed support scale, which prime powers will be activated?
2. In the subspace where the endpoints and center are eliminated, how do the minimum eigenvalues of the Archimedean, finite-place, and total matrices vary?
3. Which numerical results are worth converting into interval or rational positive semi-definite (PSD) certificates in the next version?

## II. Support and Prime Activation

The program uses

\[
\operatorname{supp}\psi\subset[-R,R].
\]

The support of the convolution square lies in

\[
[-2R,2R].
\]

Therefore, a prime power \(p^m\) only enters the finite-place matrix when

\[
m\log p<2R
\]

is satisfied. The activation threshold for the first prime, \(2\), is

\[
R>\frac{\log2}{2}
\approx0.34657359.
\]

This makes the support scan simultaneously act as a discrete prime power activation filter.

## III. Matrix Decomposition

### 3.1 Translation Correlation Matrix

For a real even basis \(\psi_j\), we define

\[
C_x(j,k)
=
\frac12\int_{\mathbb R}
\left[
\psi_j(u)\psi_k(u-x)
+
\psi_k(u)\psi_j(u-x)
\right]du.
\]

Due to compact support:

\[
C_x=0
\qquad(|x|\ge2R).
\]

The program uses FFT correlation to build the complete lag grid at once, and then interpolates at \(m\log p\).

### 3.2 Archimedean Part

After projecting onto the subspace where

\[
G(i/2)=G(-i/2)=0
\]

the endpoint terms in the explicit formula vanish. The main matrix adopts the compactly supported time-domain form:

\[
\begin{aligned}
M_\infty
={}&-(\log(4\pi)+\gamma)C_0 \\
&-\int_0^{2R}
2(C_x-e^{-x/2}C_0)
\frac{e^{x/2}}{e^x-e^{-x}}\,dx \\
&-\log(\tanh R)C_0.
\end{aligned}
\]

The last term is the analytical integral of the tail for \(x>2R\). Since

\[
\log(\tanh R)<0,
\]

this term makes a positive contribution to the matrix.

At \(x=0\), the apparent singularity of the kernel is removable, and the program uses the limit:

\[
\lim_{x\downarrow0}
2(C_x-e^{-x/2}C_0)
\frac{e^{x/2}}{e^x-e^{-x}}
=\frac12C_0.
\]

The separately calculated digamma spectral integral is only used for normalization cross-checking and does not determine the PSD result.

### 3.3 Finite-Place Part

Each activated prime power adds:

\[
M_{p,m}
=
-2(\log p)p^{-m/2}C_{m\log p}.
\]

Therefore:

\[
M_{\mathrm{fin}}(R)
=
\sum_{m\log p<2R}M_{p,m}.
\]

### 3.4 Constraint Compression

The default constraints are:

\[
G(i/2)=0,
\qquad
G(0)=0.
\]

The matrix is first projected onto the common null space of these two real linear conditions before calculating the eigenvalues.

## IV. v0.1 Actual Scan

Using 14 real even bump basis functions, we scan:

\[
R\in
\{0.25,0.30,0.346,0.40,0.55,0.70,1.00\}.
\]

The results are as follows:

| \(R\) | Activated Prime Powers | \(\lambda_{\min}(M_\infty)\) | \(\lambda_{\min}(M_{\mathrm{fin}})\) | \(\lambda_{\min}(M_{\mathrm{arith}})\) |
|---:|---:|---:|---:|---:|
| 0.250 | 0 | 0.009000 | 0 | 0.009000 |
| 0.300 | 0 | 0.008526 | 0 | 0.008526 |
| 0.346 | 0 | 0.008154 | 0 | 0.008154 |
| 0.400 | 1 | 0.009984 | -0.114920 | 0.010061 |
| 0.550 | 2 | 0.009260 | -0.847517 | 0.010354 |
| 0.700 | 3 | 0.017778 | -1.104906 | 0.014601 |
| 1.000 | 5 | 0.093406 | -1.225110 | 0.013196 |

Under this basis, constraints, and discretization, all total matrices exhibit positive minimum eigenvalues.

It is worth noting that:

\[
M_{\mathrm{fin}}
\]

itself has clear negative directions, but after adding the Archimedean part, the currently scanned subspace remains positive. This is precisely the local compensation structure that this prototype aims to observe.

## V. Grid Sensitivity

For \(R=0.4, 0.7, 1.0\), increasing the time-domain grid from 1601 to 4801 points:

- \(R=0.4\): The total minimum eigenvalue changes from 0.01006096 to 0.01006150;
- \(R=0.7\): Changes from 0.01459917 to 0.01460114;
- \(R=1.0\): Changes from 0.01322270 to 0.01316816.

The results show no sign flips, indicating that the positivity is not a direct artifact of a coarse grid. However, this remains merely a floating-point convergence test.

## VI. How to Read the Output

- `min_eigen_archimedean`: The constrained minimum eigenvalue of the infinite-place matrix;
- `min_eigen_finite`: The minimum eigenvalue of the activated finite-place matrix;
- `min_eigen_total`: The minimum eigenvalue of the total arithmetic matrix;
- `numerical_psd`: No negative eigenvalues found within floating-point tolerance;
- `archimedean_spectral_crosscheck_norm`: The difference between the time-domain main matrix and the finite-frequency digamma cross-check, used for diagnostic purposes only;
- `most_negative_vector_full`: The direction of the minimum eigenvalue of the total matrix in the current finite subspace.

## VIII. Still Incomplete

This package does not yet provide:

- Interval correlation matrices;
- Rigorous interval integration for the kernel with a removable singularity;
- Rational or interval \(LDL^T\) PSD certificates;
- Conclusions for all basis dimensions;
- Common basis import with the first package;
- Leakage control for unknown zeros outside the region;
- Any proof of the RH.

Therefore, the correct conclusion for this round is:

> In an explicit, reproducible 12-dimensional constrained subspace, scans up to a support radius of \(R=1\) have not yet found any negative directions for the arithmetic quadratic form; although the finite places individually generate negative matrix directions, they are compensated by the Archimedean contribution within the current subspace.
