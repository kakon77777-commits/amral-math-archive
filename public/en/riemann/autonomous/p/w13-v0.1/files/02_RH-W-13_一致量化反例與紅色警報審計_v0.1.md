# RH-W-13: Consistent Quantization Counterexample and Red Alert Audit

## 1. Why This Failure Must Be Preserved

The explorer previously output

$$
\lambda_{\min}\approx-3.32\times10^{-7}.
$$

If this were a strictly negative direction for a true Weil dictionary, it would be of extreme significance. Therefore, the correct engineering response is neither to publicize it nor to delete it immediately, but to escalate it to a red alert candidate and investigate it layer by layer.

## 2. Error Structure

For caching purposes, the searcher quantized the parameters of $M$ to $10^{-6}$, but the Gram matrix $G$ still used the unquantized parameters passed from the optimizer.

Thus, what was solved was

$$
M(\theta_q)c=\lambda G(\theta)c,
$$

instead of

$$
M(\theta)c=\lambda G(\theta)c.
$$

In this candidate, the minimum ordinary eigenvalue of the Gram matrix is approximately

$$
2.63\times10^{-4},
$$

and the condition number is approximately

$$
7.14\times10^3.
$$

The small parameter mismatch was therefore amplified by the generalized Rayleigh quotient.

## 3. Three-Way Results

| Path | Result |
|---|---:|
| $M$ quantized, $G$ unquantized | $-3.3206\times10^{-7}$ |
| $M,G$ consistently quantized | $+8.7636\times10^{-8}$ |
| 80-bit mpmath independent integration | $+8.7621\times10^{-8}$ |

Thus, the negative value is determined to be:

$$
\boxed{\texttt{NUMERICAL\_FALSE\_NEGATIVE\_REJECTED}}.
$$

## 4. New Mandatory Rules

1. Parameters are only allowed to be canonicalized once.
2. $M, G$, the support graph, prime-power enumeration, and the witness must share the same canonical parameter object.
3. Cache keys must be generated from the canonical object and must not be rounded independently in different modules.
4. Any negative candidate must undergo:
   - Consistent double-precision recomputation;
   - Independent integration with 80-bit precision or higher;
   - Strict interval reconstruction;
   - An exact rational witness verifier.
5. Statements such as "counterexample" or "RH is false" must not be used until all four layers are passed.

## 5. Generalized Lesson

For an ordinary eigenproblem, a small matrix perturbation is usually just a matrix error; for a generalized eigenproblem, if $M$ and $G$ come from different states, it is not an error estimation problem, but an **object identity error**.

Therefore:

> In computational mathematics, the version consistency of a shared metric is part of the theorem's input, not a software detail.
