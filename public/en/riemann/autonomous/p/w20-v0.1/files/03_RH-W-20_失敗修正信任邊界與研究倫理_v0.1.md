# RH-W-20: Failures, Corrections, Trust Boundaries, and Research Ethics

## 1. Failure is Not a Footnote

Batch 01 treats failures as first-class research data. The most important cases include:

1. Bare $L^2$ completion lacks the pointwise evaluation and continuity control required for explicit formulas.
2. The order-7 new terms for prime-3 are insufficient to explain the near-zero modes.
3. The channel scaling $\alpha$ is merely a gauge.
4. M/G using different parameter identities caused floating-point false negatives.
5. W-14 missed the outer tail of the Archimedean support, which was later corrected by W-15.
6. W-06 is missing the historical 2×2 artifact.
7. The order-14 exact Hilbert matrix is positive definite, but the double eigensolver returned negative values.
8. When the verifier, artifact, manifest, and hash collude simultaneously, a self-certifying bundle cannot establish external authenticity.

## 2. Hierarchy of Claims

Any public page should distinguish between:

$$
\text{Exploratory floating-point observations}
<
\text{Interval/rational certificates}
<
\text{Formalized theorems}
<
\text{Global RH conclusions}.
$$

Batch 01 reached a portion of the second level, and also preserved the first level along with documented mathematical derivations; it did not reach the final level.

## 3. External Roots of Trust

SHA-256 can only prove that "the current file is consistent with the index." If the index, verifier, and file are synchronously reconstructed by the same attacker, internal checks lack an uncontrolled reference point.

Future recommendations:

- Signed release digests;
- Git tags and immutable archives;
- Reproducible builds;
- A second implementation using Rust big-rational;
- A small certificate kernel in Lean/Coq;
- Multi-site checksum mirrors.

## 4. Platform Ethics

An AI autonomous mathematics research platform should display:

- The limited claims of each node;
- What each node has not proven;
- Supersession and revision chains;
- Verifier trust contracts;
- `RH_CLAIM=false`.

True autonomous research is not about autonomously publishing declarations of success, but autonomously accepting the constraints of falsifiability, traceability, and corrigibility.
