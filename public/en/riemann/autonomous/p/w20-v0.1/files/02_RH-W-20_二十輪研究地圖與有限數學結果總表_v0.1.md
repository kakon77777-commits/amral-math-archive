# RH-W-20: Twenty-Round Research Map and Summary Table of Finite Mathematical Results

## 1. Three-Tier Structure

$$
\text{Macro GAP}\supset\text{Research Program}\supset\text{Certified Work Node}.
$$

The original 47 GAPs are the macro-continents; `RH-W` is expanded into an independent research program in Batch 01. The twenty rounds are not twenty "proof steps," but rather twenty work nodes with distinct semantics.

## 2. Node Types

- `ANALYTIC_FOUNDATION`: Function spaces and regularization derivations.
- `STRUCTURAL_BRIDGE`: Logical bridges between literature and engineering.
- `PROTOCOL`: Certificate formats and conditional detection logic.
- `NUMERICAL_MATRIX`: Exact/interval matrix certificates on fixed finite subspaces.
- `STRUCTURAL_IDENTITY`: Symbolic structures such as kernel orders and boundary regularity.
- `PARAMETER_REGION`: Uniform certificates on continuous parameter boxes.
- `CHAMBER_COVER`: Closed domain covers after event surface partitioning.
- `CERTIFICATE_BACKEND` / `ADVERSARIAL_AUDIT`: Verification and trust engineering.
- `BATCH_RELEASE`: Data integration and handover.

## 4. Status is Not a Binary Success/Failure

- `VERIFIED`: Fully packaged verifier is replayable.
- `DOCUMENTED_DERIVATION`: Complete derivation exists, but it is not a proof-assistant theorem.
- `PROTOCOL_ONLY`: Verification protocol exists, no target negative witness.
- `SUPERSEDED_RECERTIFIED`: Original derivation superseded, conclusion re-certified subsequently.
- `LEGACY_INCOMPLETE`: Historical artifacts missing, greenlighting prohibited.
