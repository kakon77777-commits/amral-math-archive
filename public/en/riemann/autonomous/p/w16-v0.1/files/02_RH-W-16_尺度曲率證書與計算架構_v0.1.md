# RH-W-16: Scale Curvature Certificate and Computational Architecture

## 1. New Computational Burden in This Round

RH-W-15 fixed $h$, requiring only four $(d,\sigma)$ corner points. After incorporating $h$, the number of corner points increases to eight:

$$
2^3=8.
$$

Each corner point requires recalculating:

- endpoint block;
- constant block;
- $P_2,P_3,P_4$;
- jump-resolved archimedean block;
- exact Gram;
- activation graph.

The true time bottleneck is not $LDL^T$, but the generation of eight sets of Archimedean jump/Laplace data.

## 2. Reusable Data Layer

This package fully includes the following modules to avoid missing dependencies after extraction:

- `weil_interval_core.py`;
- `rigorous_refinement_tools.py`;
- `mixed_order_core.py`;
- `mixed_order_jump_tail.py`.

`build_interval_taylor_tube.py` is also retained as the shared computational layer from the previous round, upon which W-16 adds the eight-corner compiler for variable $h$.

## 3. Separation of Certificate and Exploration

`build_three_parameter_tube.py` is responsible for:

1. Generating eight-corner transcendental number intervals;
2. Compiling prime-power chambers;
3. Generating second-order curvature bounds;
4. Outputting the large JSON certificate.

`verify_three_parameter_tube.py` does not regenerate the transcendental matrices, but instead uses the stored intervals to reconstruct:

- three-dimensional remainders;
- knot margin;
- eight-corner exact $LDL^T$;
- Gram positive definiteness;
- fixed witness upper bounds.

Therefore, the verifier path is shorter than the builder, making it suitable for rapid replay after public release on the website.

## 4. Trust Boundaries

The certificate in this round uses:

- Python `Fraction` exact rational arithmetic;
- documented outward interval arithmetic;
- `Decimal.exp` outward rounding;
- rational logarithm/square root enclosures;
- exact rational $LDL^T$;
- independent high-precision spot checks using mpmath.

Currently, it is still not a core-verified theorem in Lean, Coq, or Isabelle. The official tag is:

```text
RIGOROUS_NUMERICAL_CERTIFICATE_UNDER_DOCUMENTED_SOFTWARE_CONTRACT
```

## 5. The Next Engineering Problem

The 3D box has been established, but if the next round directly crosses prime-power or spline-knot boundaries, a single global box will fail.

Therefore, RH-W-17 will establish chamber-aware subdivision:

$$
\text{Large parameter box}
\longrightarrow
\text{Boundary event localization}
\longrightarrow
\text{Sub-box partitioning}
\longrightarrow
\text{Per-box certificates and adjacency graph}.
$$

This will also force the Archimedean data to upgrade from "recalculated per box" to "cached by corner point and block-lag".
