# RH-W-05: Certificates and Trust Boundaries

**Version:** v0.1  
**Purpose:** To clarify which parts are mathematical identities, which parts are rigorous numerics, and which parts still rely on software trust

---

# 1. Three-Tier Certificates

This project divides the results into three tiers:

## L0: Mathematical Specifications

Includes:

- Explicit formulas;
- B-spline convolution identities;
- Support intervals;
- Exclusion of prime terms;
- Integration by parts tail bounds;
- $p$-series integral comparison.

These parts do not rely on floating-point arithmetic.

## L1: Rigorous Numeric Generation

Includes:

- Piecewise polynomials with rational coefficients;
- `Fraction` interval arithmetic;
- Rational series envelopes for $\pi$, $\log$, and $\gamma$;
- Correctly rounded values of `Decimal.exp()` expanded outward by one adjacent representable value;
- Outward rounding on a fixed decimal rational grid.

The result is complete rational upper and lower bounds.

## L2: Small exact verifier

`verify_matrix_certificate.py` only performs:

- Numerator/denominator parsing;
- Interval direction checking;
- $M_{11}=M_{22}$;
- Interval lower bounds for even and odd modes;
- Gram determinants;
- Scope declarations and `RH_CLAIM=False`.

It does not recompute exponential functions, nor does it perform floating-point eigenvalue solving.

# 2. Trust Foundation

The complete trust set for this iteration is:

```yaml
mathematical_sources:
  - Riemann-Weil explicit formula
  - B-spline convolution identity
  - integration by parts
  - p-series integral test
software:
  python: 3.13.5
  libmpdec: 2.5.1
  decimal_exp_contract: correctly rounded, ROUND_HALF_EVEN
local_code:
  - build_rigorous_matrix.py
  - verify_matrix_certificate.py
```

Binary floating-point `float` does not enter the proof path. `float()` is only used to generate human-readable decimal displays in `VALIDATION.txt`.

# 3. Acceptable Claims

```text
CERTIFIED_POSITIVE_ON_THIS_2D_SUBSPACE
```

Meaning: The Weil quadratic form is strictly positive on the two-dimensional real space spanned by the two fixed B-spline bases.

---

# 4. Prohibited Claims

All of the following are invalid:

```text
RH_PROVED
WEIL_FORM_GLOBALLY_POSITIVE
ALL_SUPPORT_RADII_POSITIVE
NO_OFF_AXIS_ZERO_EXISTS
FINITE_MATRIX_IMPLIES_RH
```

# 5. Next-Level Trust Reduction

To remove the software contract of `Decimal.exp()`, a fully self-contained rational exponential verifier can be added:

1. Reduce the range of $x$ in binary to $y=x/2^m$;
2. Bound $e^y$ using a positive-term Taylor polynomial;
3. Bound the remainder term with a geometric series bound;
4. Perform $m$ rational interval squarings;
5. Compare whether the result contains the current Decimal interval.

This task is registered as:

```text
RH-W-05-FORMAL-BACKEND
```
