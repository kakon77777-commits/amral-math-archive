# RH-W-19: Error Certificate Zoo and Detection Matrix

## Four-Layer Error Classification

### A. Package and Execution Layer

Includes hash tampering, unindexed programs, path traversal, dependency cycles, and state bloat. These errors are rejected before the native verifier executes.

### B. Mathematical Semantics Layer

Includes $M/G$ parameter identity mismatch, missing prime powers, chamber piece misplacement, and closed cover gaps. Even if the hash is recomputed, they must be rejected by mathematical reconstruction.

### C. Interval and Numerical Layer

Includes inward rounding, endpoint inversion, tail term omission, and floating-point false negatives. These cases demonstrate that "high precision" and "strict enclosure" are not synonymous.

### D. External Trust Layer

`TOKEN_ONLY_COLLUDING_VERIFIER` can survive under a self-certification model. Its risk can only be mitigated through an external trust root or independent implementations.

## Detection Principles

| Error | Cannot Rely Solely On | Requires |
|---|---|---|
| Parameter mismatch | hash | mathematical reconstruction |
| Missing prime power | matrix positivity | support enumeration |
| Knot misplacement | activation set | polynomial-piece identity |
| Inward interval | decimal digits | exact rational enclosure |
| Floating-point false negative | eigensolver sign | exact/interval factorization |
| Tail term omission | finite partial sum | rigorous remainder |
| Verifier collusion | package self-hash | external trust root |

## Core Prohibitions

1. Do not publish a negative Weil witness based solely on numpy.linalg.eigvalsh < 0.
2. Do not substitute printing decimal digits for outward intervals.
3. Do not substitute identical active primes for identical complete chamber identities.
4. Do not claim issuer identity using an in-package hash.
5. Do not treat an expected token as proof of verifier correctness.
