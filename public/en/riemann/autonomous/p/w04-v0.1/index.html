RH-W-04: Finite-Dimensional Completeness and Rational Negative Certificate

Constructs an explicit nested cutoff–Fourier finite-dimensional dictionary, proving that its Rayleigh–Ritz minimum must converge to the true spectral bottom. It also reduces the rigorous negative certificate to "a rational vector + a set of rational interval matrices + a small verifier using only fractions.Fraction". The demonstration verifier correctly accepts exact negative certificates and correctly rejects floating-point candidates that appear to be negative.

SPECIFICATION_COMPLETE / ENTRY_ENCLOSURES_OPEN — The positioning stated by the document in the package: "Not an RH proof; establishes the finite-dimensional reachability of the Weil quadratic form and machine-verifiable negative certificates," reproduced exactly as is. The rigorous interval envelope of the genuine zeta Weil matrix is not yet complete.
