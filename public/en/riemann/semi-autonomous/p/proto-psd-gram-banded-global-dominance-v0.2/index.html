PSD Gram Banded Global Dominance

PSD Gram Banded Global Dominance v0.2 — Replaces the diagonal ray cone of the previous package with full PSD Gram variables. The cross terms are indeed effective (sample budget reduced by 21.08% on average), but the improvement is far from sufficient to approach the target; the [18,23] axial band accounts for an average of 61.73% of the sample target.

RH_CLAIM = False — The execution environment lacks a convex SDP solver; the package uses A=LL^T decomposition + multi-start SLSQP for constructive solving, claiming neither global SDP optimality nor interval certificates, reproduced as is. This is not an RH proof, nor is it a global zero-side certificate.
