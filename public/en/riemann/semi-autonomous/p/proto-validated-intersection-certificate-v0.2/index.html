Validated Intersection Certificate

Validated Separation–Positivity Intersection Certificate v0.2 — Reconstructs the floating-point candidates of v0.1 into explicit piecewise linear functions, establishing interval certificates for both the regional negative direction and arithmetic positivity separately; all 480 sub-rectangles are certified, with 0 pending.

RH_CLAIM = False — The certificate_summary.txt within the package self-reports certificate_passed=True, and the scope_warning field defined by CERTIFICATE_SCHEMA.md explicitly states the non-RH status, reproduced exactly as is. This is a replayable validated-numerics certificate, not a verified formal proof; it neither proves nor disproves the Riemann Hypothesis.

Positive floating-point values cannot be directly treated as strict arithmetic lower bounds. v0.2 no longer uses black-box arrays, but reconstructs the candidate into an explicit piecewise linear function, and then establishes interval certificates for both signs separately." — Excerpt from §1 of the technical notes in this package.
