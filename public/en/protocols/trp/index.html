Protocol v0.1 2026-08-11

TRP — Triadic Research Protocol

Bold Discovery · Hostile Verification · Neutral Assessment. Three roles hand off in sequence: Agent A is responsible for the highly divergent, high-confidence main push — it may propose bold conjectural bridges and does not stop researching out of fear of hallucination, but every unproved step must be flagged; Agent B does not generate, only hunts for problems — specifically the first illegal step, checking quantifier order, domain, uniformity, error terms, tail behavior, local-to-global jumps, counterexamples, and "proves-too-much" red flags (an argument strong enough to also derive a known-false statement); Agent C neither generates nor challenges, only renders a neutral academic judgment — what is currently the strongest defensible claim, what completion level it has reached, whether it is novel, whether QCI is closed, whether it's ready to submit, and what objections a referee would most likely raise.

Bold generation ≠ bold public claim — TRP's core principle: bold generation is allowed; bold generation becoming a public claim directly is not.

Agent A — Aggressive Discovery

  • Highly divergent;
  • Highly exploratory;
  • A confident main push;
  • May propose bold conjectural bridges;
  • Does not stop researching out of fear of "hallucination";
  • But every unproved step must be flagged.

Agent B — Adversarial Proof Audit

Hunts specifically for the first illegal step; checks at minimum include:

  • Whether quantifier order has been silently swapped;
  • Whether the domain is consistent;
  • Whether uniformity holds;
  • Whether error terms have been ignored;
  • Whether tail behavior has been handled;
  • Whether a local-to-global jump is legitimate;
  • Whether a counterexample exists;
  • Whether the argument proves too much (whether it can also derive a known-false statement);
  • Formal gaps.

Agent C — Neutral Academic Assessment

Judges only:

  • The strongest defensible claim currently available;
  • Completion level;
  • Novelty;
  • Whether QCI is closed;
  • Publication readiness;
  • Likely referee objections.

TRP Round Display Format

If a case uses TRP, the suggested per-round presentation format is as follows (not yet applied to any existing case):

Round 001

Agent A — Candidate
Status: COMPLETE

Agent B — Audit
Status: GAP_FOUND

Agent C — Assessment
Level: 2

Next:
