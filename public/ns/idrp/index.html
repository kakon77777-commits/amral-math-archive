NS-IDRP

Navier–Stokes Impulsive Defect Recurrence Program · Cycle IX · 4/4 已建置 · 全域正則性 OPEN

NS-IDRP 是研究鏈裡第一條接續在 NS-DCRP 之後的子線——本文自己開篇就寫著 「DCRP Cycle VIII 以倖存正規形式 𝒦_IDR(瀰散脈衝復發)收尾」,首次明確證實 NS-DCRP 正是 Cycle VIII。核心新問題是時間性的:每個正向載體是否只能存在於孤立時刻,使每個時空預算都 保持可加總?四篇一路推進:IDRP-01 分離持續性與爆發債務,IDRP-02 證明過濾痕跡 快速損失並非機制不可見,IDRP-03 部分封閉爆發到缺陷實現(BDR)問題,IDRP-04 完成 Cycle IX 終審。

IDRP-04 的結論是:僅靠壓力的來源橫向性一般不可能,更強的「強迫配對到來源缺陷」定理也不成立,普遍弱來源作用 預算在尺度上可加總——因此本身無法提供物理臨界提升。Cycle IX 把倖存障礙化簡成一個切向奇異脈衝幻影 (TSIP),正式交棒給「NS-TSKR:Navier–Stokes 切向奇異核剛性計畫」。目前確認的完整 研究鏈:NS-CSP(II)→ NS-DRC(III)→ NS-ANP (IV)→ NS-CFOP(V)→ NS-FCBP(VI)→ NS-MORP (VII)→ NS-DCRP(VIII)→ NS-IDRP(IX)→ NS-TSKR(X)→ NS-RKAP(XI)。

Cycle IX 四篇 · The Four-Paper Cycle

依賴鏈:持續性/爆發二選一 → 爆發可見性 → 爆發到缺陷實現 → 封階稽核。 建議照順序讀,每一篇都以前一篇的結果為前提。

IDRP-01

脈衝持續性、痕跡增厚與復發缺陷正規形式

分離持續性與爆發債務,證明能量類持續性下限,但一般模數太弱、無法迫使拋物厚化。Cycle IX 開篇。

 IDRP-02

來源脈衝可見性與移動視窗耗盡

證明過濾渦度痕跡的快速損失並非機制不可見,定義爆發到缺陷實現(BDR)橋接問題。

 IDRP-03

相對隱形爆發核與對偶相容 BDR

透過有限窗來源商證明部分 BDR 下界,證明緊緻族移動視窗定理排除相對隱形爆發。

 IDRP-04 · 終審

來源橫向性、伴隨同步與 Cycle IX 封階稽核

證明僅靠壓力的來源橫向性不可能。化簡出切向奇異脈衝幻影,交棒 NS-TSKR。
