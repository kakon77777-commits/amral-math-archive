C6-A:Certified Defect Graph、Typed Cycle Composition 與 Minimal Survivor Candidates

C6 正式啟動,任務從 C5 的 state construction + compactification + debt routing 轉向 cycle extraction + cycle compatibility + cycle elimination。本輪第一個目標看似簡單——對 C5-M 的 finite defect graph 做 SCC extraction——但立刻出現關鍵修正:普通 label-level SCC 並不足以證明 PDE recurrent cycle,因為粗邊可能只對子型別成立、邊帶有額外 metadata、兩條各自合法的邊未必首尾相接、`not ruled out` 自環不是轉換定理、外部正則性閘門是匯點不是普通轉換、許多 C5 routing 本質上是 disjunctive hyperedge。因此本輪先建立 Certified Typed Defect Transition System:四種邊語意——$I$(implication,已證定理)、$C$(conditional implication,需額外閘門)、$N$(non-exclusion,僅代表「目前未排除」,不是轉換定理)、$E$(external kill edge,指向 REG 的發表定理閉合)——並為每個殘餘類定義完整 metadata 空間 $\mathcal K_T,\mathcal K_G,\mathcal K_P,\mathcal K_H,\mathcal K_F$,把每條邊寫成型別化關係 $R_e\subset\mathcal K_X\times\mathcal K_Y$ 而非裸標籤箭頭,並把 C5 常見的 disjunctive routing($X\Rightarrow Y_1\vee Y_2\vee Y_3$)正式編碼成 hyperedge 而非三條並行的強制邊。把 C5-M 所有 candidate/conditional/not-yet-excluded 箭頭投影成普通 digraph,得到 $V_6=\{T,G,P,H,F\}$(排除 $A$,因為它可能只代表 proof-entry legality 缺陷而非物理奇異機制)上的 may-graph,SCC 分解得到 $\{T\}$ 與 $\{G,P,H,F\}$——但 C6-A.1 Projected-SCC No-Go 證明 $X\leftrightarrow Y$ 在投影圖中成立並不蘊含存在真正首尾相接的 $(\theta_X,\theta_Y)$ 對:前一條邊產生的 target metadata 未必落在後一條邊的 source antecedent 內。因此定義 cycle compatibility fiber product $\mathfrak C(e_1,\ldots,e_m)=R_{e_1}\times_{\mathcal K_{X_2}}\cdots\times_{\mathcal K_{X_1}}R_{e_m}$,C6-A.2 Composable Cycle Criterion 要求全部邊皆為 I/C 狀態、條件相容、fiber product 非空、無自動觸發外部 REG 閘門、且復發疊代保持 legality/scale/time metadata——並進一步區分 projected cycle、composable cycle、recurrent cycle 三個嚴格遞增的層級,composable 不等於 recurrent。逐一審計三個候選:候選 $T$ 僅是 $T\overset{N}{\looparrowright}T$(C5-C 的純量時間 no-go 未構造真正復發軌道,是 candidate trap 不是 certified self-cycle);候選 $G\leftrightarrow P$(C6-A.3)正向靠強中間相干幾何逼壓力重返,反向靠壓力軸鎖定,但 C5 未證明前者產生的 $P$ 態自動滿足後者的 antecedent,四項組成義務 GP-1 至 GP-4(來源連續性、簽名相容、軸相容、復發性)無一自動成立;候選 $H\leftrightarrow F$(C6-A.4)的 $H\to F$ 已有 C5-J/L 的嚴謹子型別 routing($\text{TURNOVER}\Rightarrow\text{VISC}\vee\text{PROJECTED-NL}$),但反向 $F\to H$——高階強迫壅塞是否真的重新生成 theorem-legal 的下一代 persistent bad window——目前只是結構性猜想,五項組成義務 HF-1 至 HF-5(強迫到振幅、振幅到定理入口、定理入口到窗口失敗、外部閘門迴避、復發縮放)同樣無一自動成立。C6-A.5 Finite-Budget Cycle Exclusion Lemma 證明:若復發循環代際總負債有限且逐代負債下界為正,則只有有限多代可以發生——但三個候選循環的負債($T$ 的純量時間代價、$G/P$ 的壓力臨界質量、$H/F$ 的全階黏性/非線性翻轉代價)都可能隨空間尺度、導數階、窗口長度收縮而趨零,目前沒有已知的一致正 global toll 排除任何一個,critical saturation($b_n\downarrow0$)是尚未排除的逃逸模式。核心結論(C6-A.6):目前沒有任何非平凡 recurrent PDE defect cycle 被真正 certified,但也沒有一個候選被證明不可能——ordinary SCC 只是 survivor kernel 的 over-approximation(C6-A.7),必要但不充分。三個候選依優先序排列:Priority 1 — $H/F$(理論介面最成熟、debt 變數最明確、只缺一條 sharply formulated 的反向邊);Priority 2 — $G/P$(有限維矩陣障礙已具備,壓力來源相容性是主要不確定性);Priority 3 — $T$(純量 no-go 強,但通用時間-空間 PDE 耦合定理仍缺)。正式交棒下一篇 C6-B — High-Order Forcing Re-entry, Bad-Window Regeneration, and the $H/F$ Cycle Test,八項組成義務(B1 強迫事件正規化 至 B8 循環證實/否證),目標是判定「高階黏性/投影非線性強迫是否真的能重新生成一個 theorem-legal 且整個容許窗口都 sign-thick 的下一代缺陷」——不論答案是或否,都是高價值結果。

對 C5-M 的 finite defect graph 做 SCC extraction,但證明普通 label-level SCC 不足以證明 PDE recurrent cycle。建立四種型別化邊語意(I/C/N/E)與 typed transition relation,把裸標籤箭頭換成型別化關係,disjunctive routing 正式編碼成 hyperedge。審計三個候選復發循環——時間 $T$、幾何-壓力 $G\leftrightarrow P$、高階強迫 $H\leftrightarrow F$——全部只是 candidate,沒有一個被 certified,也沒有一個被排除。Finite-Budget Cycle Exclusion Lemma 證明若負債一致有正下界則循環只能有限多代,但目前沒有任何候選被證明滿足這個下界。最成熟的候選是 $H\leftrightarrow F$,正式交棒 C6-B 專攻其缺失的反向邊。 — 包內文件自陳的階段性狀態,原樣照登。
