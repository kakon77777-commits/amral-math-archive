C6-D:Geometry–Pressure Cycle Composition、Provenance Compatibility 與 Signature-Return Tests

C6-A 排名第二的候選 $G\leftrightarrow P$ 現在接受同樣的 cycle-composition 審核,一開始就發現它比 $H/F$ 更需要語意修正:C5-D/F 裡許多寫成 $G\to P$、$P\to G$ 的箭頭,其實全部發生在同一個時刻、同一個空間核心、同一條壓縮軸、同一個 local/far 壓力分解上——不是 $G_n\to P_n\to G_{n+1}$ 的序列邊,而是一個 same-event compatibility relation $(G,P)_n\in\mathcal C_{GP}$。真正的復發循環還需要一張獨立的時間回歸映射 $\Phi_{GP}:\mathcal C_{GP,n}\dashrightarrow\mathcal C_{GP,n+1}$,C5-D/F 從未證出。為此在 C6-A 的證明狀態標籤(I/C/N/E)之外,再加一維邊語意 $\tau_e\in\{S,D,E\}$(Static 同事件關係、Dynamic 跨代轉換、External 外部封閉),C6-D.1 Static-Edge Collapse Principle 證明:同事件的相容性迴圈應該在做 SCC extraction 之前先商掉,不能直接當成循環邊。追溯 $G\to P$ 實際產生什麼:strong-middle geometry(透過 adjoint mean-strain evolution 與 mean-stability gate)只給出總體局部化壓力 Hessian 均值 $P_\chi=\int\chi\nabla^2p$,而不是直接的遠場壓力——比舊粗糙 $P\to G$ 軸鎖定路線預設的前提弱得多。C6-D.2 Pressure-Provenance Split Lemma 用 Bradshaw–Tsai 局部壓力展開把它拆成 $P_\chi^{loc}+P_\chi^{far}$,oriented response 只保證析取式 $P_{\rm local}^{+}\vee P_{\rm far}^{+}$——循環必須先選一個 provenance 分支,只有 far 分支才有資格用調和 STF 矩陣簽名/軸鎖定,local 分支不能偷用 far-pressure 的障礙機制。若 far 分支確實主導,C6-D.3 Far-Pressure Axis-Margin Theorem 給出同一核心壓縮軸上精確的負向二次型邊際;簽名三分:one-negative $(-,+,+)$ 才產生窄投影錐軸鎖定(C6-D.4 證明這與 Q-zero-barycenter/七點抵銷同事件不相容——但這只是同事件不相容,不是「未來事件」定理),two-negative $(-,-,+)$ 只給出較寬的負帶/平面幾何,不鎖單一軸,相容性不等於因果性(C5-F 從未證明 $(-,-,+)\Rightarrow$ Q 抵銷或幾何缺陷生成),$\det F=0$ 是簽名邊界。全輪最關鍵的一步(C6-D.5 Pressure-Alone Dynamic Return No-Go):應變演化方程同時含平流、黏性、$S^2$、渦度二次項、壓力五項,壓力 Hessian 單獨不能決定未來的 $\lambda_2$ 符號、中間縫隙、壓縮軸或 Q-抵銷幾何——因此同事件 P/G 相容性在沒有明確的 heredity/persistence 定理之前,不能被升格成未來幾何邊。C6-D.6 Joint-State Recurrence Requirement 因此證明:舊粗糙 $G\leftrightarrow P$ 只有在存在一個非空復發不變集 $\mathcal R_{GP}\subset\mathcal K_{GP}^{comp}$ 且 Navier–Stokes 演化真的把它映回自身時才算真正的動力循環——C5-D/F 完全沒有這樣的定理,粗糙 $G/P$ 動力循環正式判死。把復發所需的八維儲備(geometry、mean-rotation depletion、far capture、provenance coherence、signature distance、axis margin、far-matrix heredity、geometry heredity)壓成向量 $\mathbf R^{GP}$,C6-D.7 Finite GP Recurrence Bottleneck Theorem 證明與 C6-C 同型的二分法:任何無窮候選聯合復發世代取子序列後,要嘛一致遺傳/相干,要嘛逼近九個具名邊界之一(中間縫隙塌縮、平均旋轉接管、局部壓力接管、來源相容性抵銷、簽名邊界、軸邊際塌縮、遠場遺傳塌縮、幾何遺傳塌縮、壓力正則性出口)。全輪最重要的整體結論(第 50 節):經過 C6-B/C/D 的語意精煉後,C5-M 粗糙圖上的兩個主要候選——通用 $H/F$ 循環、動力 $G/P$ 循環——都被正式移除,真正剩下的物理候選只剩三個:可能孤立的 $T$、遺傳性 $GP_{\rm hereditary}$、非線性相干 $HF_{\rm nonlinear\ coherent}$——比 C5-M 原本的粗糙圖所暗示的循環前沿小得多。由於 $T$ 是 C6-A 三個原始候選中唯一還沒做過 composition audit 的,且若 $T$ 無法保持孤立,所有物理倖存者候選都可能收斂進已經被型別化的兩個聯合相干分支,正式交棒 C6-E — Temporal-to-Spatial Shared-Source Coupling, Isolation No-Go Tests, and the Fate of the $T$ Trap,八項組成義務(E1 定義真正的時間來源載體 至 E8 循環圖重新計算)。

發現 C5-D/F 裡許多 $G\to P$、$P\to G$ 箭頭其實都發生在同一事件上,不是跨代序列邊,而是 same-event compatibility relation,真正復發需要一張獨立的時間回歸映射,C5-D/F 從未證出。壓力響應必須先分裂成 local/far 兩支,只有 far 分支能用簽名/軸鎖定機制;簽名三分(one-negative 窄軸鎖定、two-negative 只給寬帶、det=0 邊界)全部只是同事件相容性,不是未來幾何的因果定理。應變演化方程五項同時作用,壓力單獨不能決定未來幾何,粗糙 $G\leftrightarrow P$ 動力循環正式判死。全輪最重要的結論:經過 C6-B/C/D,C5-M 粗糙圖的兩個主要候選循環(通用 $H/F$、動力 $G/P$)都被移除,真正剩下的物理候選只剩三個——可能孤立的 $T$、遺傳性 $GP$、非線性相干 $HF$——比原本暗示的小得多。交棒 C6-E 專攻最後一個未審計的候選 $T$。 — 包內文件自陳的階段性狀態,原樣照登。
