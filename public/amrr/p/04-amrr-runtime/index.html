自主數學研究 Runtime:從可定址認知到自主理論建構

把 Paper 01–03 收斂成第一版可執行架構。正式定義 AMRR = ACR + MathematicalState + Gap 診斷引擎 + Constrained 修補引擎 + Problem/Theory Store + 數學義務引擎 + 驗證器路由 + 理論橋接層 + CTCL-ITR 數學事件 + 持續研究迴圈,九層疊加在 ACR(一個更通用、獨立、已有自己 MVP 的認知 runtime)之上,設計原則第一條就是「Integrate > Rewrite」——明確只延伸 ACR,不重寫、不打造第二套平行的 agent 架構。列出 M0 至 M11 共 12 個實作階段的規劃、依賴關係與各自的驗收條件,並明言除非後續 release artifact 通過對應關卡,規劃文字本身不能回寫成「已實作」。

AMRR 是疊加在 ACR 之上、不修改 ACR 核心的九層數學研究擴充;M0–M11 十二階段的實作狀態必須以實際通過驗收關卡的 release artifact 為準,不能以規劃文件本身作數 本文明言的不主張清單:不做完全自主發表、不做無界公理創造、不做無監督基礎理論替換、不宣稱普遍新穎性或普遍數學正確性、不做自動社群接受判定、不做哲學意識判斷、不主張法律數學人格。實際範圍窄得多:系統能否在受控環境下持續診斷、修補、驗證、留下紀錄,不需要人類每一步都給提示——不是「這個 AI 是不是數學家」。
