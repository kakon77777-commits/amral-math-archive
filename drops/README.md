# drops

Neo puts raw material here directly (this repo is checked out locally, so no upload
step is needed) — one top-level folder per project or line, named however makes sense
at the time (e.g. `NS/`, `CCM-followups/`). No fixed structure imposed in advance:
zips, loose `.md` files, whatever the source naturally is, gets read as-is.

Once something here has been read and built into the site (`../public/`), it's done —
this folder is intake, not an archive of what's already been processed.
